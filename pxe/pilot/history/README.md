# Retained pilot history

Historical proposals, retired console enrollment and incomplete custom VM runner
are grouped here to keep the active tree small. Start at [PXE README](../../README.md).
No private inputs, credentials or raw operator evidence are moved into this tracked
history. Recorded command paths describe their original execution location.

- `console/`: retired enrollment/recovery helpers and preserved offline tests.
- `*-PROPOSAL.md`: original reviewed staging/activation/packet contracts.
- `rehearsal/`: unfinished custom VM/session experiment, NOT an execution path.
  Its first full mock failed memory parsing before resource creation. Original
  layout-relative references are preserved; do not run it from this archive.

Proven activation/shutdown, templates and packet fixtures remain in `pilot/`.

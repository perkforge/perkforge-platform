# Historical Fleet effort

Read-only reference for the superseded custom PaaS/Fleet deployment. This is not an active deployment option. Do not run its rebuild/deploy scripts against the Big Bang cluster. Historical handoffs, tests, synthetic fixtures and evidence producers are retained to avoid losing assurance work. Old commands and environment state are not current instructions.

Infrastructure primitives reused by the current platform live under `infrastructure/`; Big Bang configuration and active tests live under `big-bang-bootstrap/`. See the repository evidence inventory for adaptation limits. No separate application or enrollment repository has been removed.
